# Changelog

Notable changes to GREETA are documented here.

## [1.0.0] - 2026-11-02

### Added

- Pixel-inspired LightDM login interface with responsive layout.
- Pixel Mates characters and interactive ambience controls.
- Weather, daypart, wallpaper, theme color, density, and wind preferences.
- Safe LightDM WebKit greeter integration with preview and smoke-test modes.
- Cinnamon Screensaver theme integration that retains native authentication.
- Browser-based visual demo; authentication and power actions are unavailable.
- Indonesian project documentation and MIT license for project code.
